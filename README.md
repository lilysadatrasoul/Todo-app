# Todo App

A simple Todo application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Delete tasks
- Edit tasks
- Mark tasks as done
- Filter tasks by All, Done, and Pending
- Show total, done, and pending task counts
- Sort tasks
- Save tasks in localStorage
- Show task creation date and time
- Clear all tasks

## Technologies

- HTML
- CSS
- JavaScript
- localStorage
